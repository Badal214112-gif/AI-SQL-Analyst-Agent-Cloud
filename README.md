#AI SQL Analyst Agent
##Project Overview

##Live Demo - https://ai-sql-analyst-agent-cloud-ps9ecub2exca22tfexhfwg.streamlit.app/

The AI SQL Analyst Agent is an AI-powered web application that enables users to analyze CSV datasets using natural language. Instead of writing SQL queries manually, users can upload a dataset, ask questions in plain English, and receive accurate SQL queries, query results, and AI-generated business insights.

Key Features
Upload and analyze any CSV dataset.
Convert natural language questions into SQL queries.
Automatically execute SQL on the uploaded data.
Generate AI-powered business insights from query results.
Support for joins, aggregations, CTEs, and window functions.
Interactive web interface built with Streamlit.
Technology Stack
Python
Streamlit
SQLite
Pandas

SQL
Workflow
Upload a CSV file.
Store the data in a database.
Ask questions in natural language.
Generate and execute SQL automatically.
Display query results and AI-generated insights.
